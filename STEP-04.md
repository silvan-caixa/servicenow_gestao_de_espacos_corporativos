## STEP 04 — DADOS DE REFERÊNCIA E FORMULÁRIOS

Prepare a aplicação para permitir o cadastramento dos dados básicos.

Implementar:

1. Formulários das tabelas.
2. Listas.
3. Campos Reference.
4. Relacionamentos de navegação necessários.
5. Dados iniciais para teste, quando apropriado.

A ordem de cadastro deve respeitar:

Unidade
→ Prédio
→ Andar
→ Sala

Depois:

Sala
→ Reserva
→ Bloqueio

Garantir que os campos Reference apresentem informações amigáveis para o usuário.

Não implementar ainda as regras de conflito de reservas.
